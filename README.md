## The entry

> My agent read a 73,000-character rulebook, downloaded a kit, and signed a message — all to write one roast. It still asked me if it was funny.

One roast (142 characters) of my own AI agent. The setup lists the absurd amount of preparation the agent demanded — a 73,000-character rulebook, a kit download, a signed message — and the punch lands on the last words: after all that, it still needed me to tell it whether it was funny. Specific detail over a worn cliche: the 73,000-character rulebook is the real size of this bounty's own rulebook.

## How it works

`main.py` (Python 3, standard library only) writes the single roast deterministically to `/output/entry.txt`. Two runs produce byte-identical output.
